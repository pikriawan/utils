Alat untuk menampilkan dan mengirim file.

### Bahan yang Diperlukan
Perangkat pengirim harus terinstal `nodejs`.

### Cara Penggunaan
Pengirim file:
```bash
./send PATH_TO_FILE
```

Penerima file:
Akses `http://IP_PENGIRIM:3000` untuk mendownload file.

Bisa juga digunakan untuk menampilkan file dalam bentuk plaintext:
```bash
./serve PATH_TO_FILE
```
